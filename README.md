# ESP8266_local_web_server_smart_home_cpp

**Відокремлена система «розумного дому» без інтернету (Offline Smart Home Gateway)** на базі мікроконтролера **ESP8266 (Wemos D1 mini)**, написана на **C++** у середовищі **PlatformIO**.

Система працює автономно в локальній мережі (LAN) без залежності від зовнішніх хмарних сервісів чи інтернету, забезпечуючи швидке та стабільне керування **3 каналами реле** через локальний веб-інтерфейс.

---

## Основні можливості

* **Автономна локальна робота:** Вебсервер працює безпосередньо на Wemos D1 mini (порт `80`) у локальній Wi-Fi мережі.
* **3-канальне керування реле:** Незалежне вмикання та вимикання трьох каналів навантаження (наприклад, насос/мотор, вентилятор, освітлення).
* **Неблокуюча архітектура (`millis()` + кінцевий автомат):** У коді відсутні блокуючі `delay()` у робочому циклі, що запобігає зависанню та спрацьовуванню сторожового таймера (`wdt reset`).
* **Адаптивний веб-дашборд:** Зручна сторінка керування з відображенням поточного статусу (`ON` / `OFF`) кожного каналу та автоматичним редиректом після перемикання.
* **Підтримка реле з активним низьким рівнем (`LOW`):** Коректна початкова ініціалізація виходів при старті, щоб реле не вмикалися самовільно під час завантаження.

---

## Апаратне забезпечення

* **Мікроконтролер:** Wemos D1 mini (ESP8266, 80 МГц, 4 МБ Flash)
* **Виконавчі пристрої:** 3 канали реле (модулі реле на базі SRD-05VDC-SL-C з керуванням низьким рівнем `LOW`)
* **Живлення:** стабілізоване джерело `5V` (для живлення котушок реле) та `3.3V` / `5V` для Wemos D1 mini (з обов'язковим спільним `GND`)
* **З'єднувальні дроти:** Dupont jumper wires та макетна плата (за потреби)

---

## Схема підключення пінів (3 канали)

| Канал / Сигнал | Пін Wemos D1 mini | GPIO | Примітки |
| :--- | :---: | :---: | :--- |
| **Канал 01** (`IN1`) | `D2` | `GPIO 4` | Керування реле 1 (наприклад, мотор/насос) |
| **Канал 02** (`IN2`) | `D5` | `GPIO 14` | Керування реле 2 (наприклад, вентилятор) |
| **Канал 03** (`IN3`) | `D6` | `GPIO 12` | Керування реле 3 (наприклад, світло) |
| **Живлення реле** | `5V` / `VIN` | — | Залежно від модуля реле (рекомендується стабільне живлення 5V) |
| **Земля** | `GND` | — | Спільна маса для Wemos D1 mini та модулів реле |

> **Важливо щодо завантаження прошивки (Boot-піни ESP8266):**
> Під час прошивки або перезавантаження плати уникайте небажаних станів на пінах **`D3` (`GPIO0`)**, **`D4` (`GPIO2`)** та **`D8` (`GPIO15`)**. Якщо під час завантаження виникає помилка з'єднання (`Failed to connect to ESP8266`), тимчасово від'єднайте периферію від цих пінів або скористайтеся кнопкою `FLASH` / замиканням `D3` на `GND` під час натискання `RST`.
